Procedura per i Colleghi (Start-up)
1. Aggiornamento Codice Scaricare l'ultima versione del progetto con le modifiche al docker-compose.yaml e al codice Python.

Bash

git pull
2. Primo Avvio (Generazione Volumi) Avviare tutto. InfluxDB partirà, ma Telegraf e Python falliranno (o daranno errore) perché manca ancora il token. È normale.

Bash

docker compose up -d --build
3. Generazione del Token Chiedere a InfluxDB di creare un token amministratore.

Bash

docker exec influxdb3 influxdb3 create token --admin
(Copiare la stringa lunga che esce).

4. Configurazione Token Incollare il token in due posti:

Nel file .env alla voce INFLUXDB_TOKEN=...

Nel file telegraf.conf alla voce token = "..."

5. Riavvio per applicare le modifiche (FONDAMENTALE) Ora che i file sono aggiornati, bisogna dire a Python e Telegraf di rileggerli.

Bash

docker compose restart telegraf
docker compose up -d --force-recreate catalog-api
(Usiamo --force-recreate su catalog-api per essere sicuri che rilegga il file .env).
